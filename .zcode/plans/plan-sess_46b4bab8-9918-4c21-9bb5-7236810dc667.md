# 🪟 پیاده‌سازی UI شیشه‌مایع (Liquid Glass) به سبک iPhone برای Monetra

## Context
Monetra یک اپ مالی با Jetpack Compose + Material 3 است که در حال حاضر UI آن از Surface های مات با بوردر ساده (۱dp hairline) استفاده می‌کند. هدف: بازطراحی کامل ظاهر به سبک **Liquid Glass اپل (iOS 26)** — پنل‌های شیشه‌ای نیمه‌شفاف، لبه‌های نورانی، هایلایت اسپکولار، بلور واقعی پشت عناصر شناور، و پس‌زمینه گرادیان رنگی زنده — روی هر ۱۴ صفحه اپ، با حفظ کامل معماری MVI، RTL، فونت وزیرمتن و اعداد فارسی.

**انتخاب‌های تأییدشده توسط کاربر:** بلور واقعی با کتابخانه Haze + پس‌زمینه گرادیان زنده مانند iOS + کل اپلیکیشن.

---

## ۱. وابستگی‌ها
- `gradle/libs.versions.toml`: افزودن `haze = "2.1.0"` و کتابخانه‌های `dev.chrisbanes.haze:haze` + `dev.chrisbanes.haze:haze-glass`
- `app/build.gradle.kts`: `implementation(libs.haze...)` (minSdk 26 پشتیبانی می‌شود؛ روی API < 31 بلور با fill شیشه‌ای جایگزین می‌شود)

## ۲. لایه تم — `core/designsystem/theme/`
- **`GlassTheme.kt` (جدید):** `data class GlassColors` (fillTop/fillBottom/strokeStart/strokeEnd/sheen/shadow) + `LocalGlassColors` + اکسسور `MaterialTheme.glassColors` — نسخه Light و Dark
- **`Color.kt`:** رنگ‌های پس‌زمینه Aurora (Light: هاله‌های پاستلی بنفش/آبی/فیروزه‌ای روی پایه `#F4F6FD` — Dark: هاله‌های اشباع تیره روی پایه `#070B16`) + fill های شیشه (Light: سفید ۵۵٪→۲۵٪ — Dark: سفید ۱۰٪→۴٪)
- **`Shape.kt`:** شعاع‌ها بزرگ‌تر و iOS-like: small 14 / medium 18 / large 24 / extraLarge 32
- **`Dimens.kt`:** توکن‌های جدید (navBar 72→ ارتفاع شیشه‌ای، ضخامت stroke و...)
- **`Theme.kt`:** ارائه `LocalGlassColors` در `AppTheme`

## ۳. اصول پایه شیشه — پکیج جدید `core/designsystem/glass/`
- **`LiquidGlassBackdrop.kt` (جدید):** پس‌زمینه تمام‌صفحه Aurora: گرادیان پایه + ۴-۵ لکه radial رنگی با `Modifier.blur` (API 31+؛ در نسخه‌های قدیمی‌تر گرادیان‌های نرم بدون بلور) + انیمیشن آرام حرکت لکه‌ها (حس liquid)
- **`GlassSurface.kt` (جدید):** کامپوننت پایه‌ی همه پنل‌ها — fill گرادیانی نیمه‌شفاف + بوردر گرادیانی ۱dp + هایلایت specular لبه بالا + سایه نرم + انیمیشن press (scale 0.97 با spring). **بدون بلور** (ارزان؛ مناسب کارت‌های لیست — پس‌زمینه Aurora ذاتاً نرم است)
- **`GlassHaze.kt` (جدید):** فقط برای عناصر شناور (نوار پایین/FAB): `rememberHazeState` + `Modifier.hazeSource/hazeGlass` طبق API رسمی Haze 2.x با `GlassStyle.regular`؛ کل مصرف Haze در همین فایل + AppNavigation ایزوله است تا در صورت تفاوت جزئی API، اصلاح فقط اینجا انجام شود

## ۴. بازطراحی کامپوننت‌ها — `core/designsystem/components/` (الگوی یکسان: هر Surface/Card مات → GlassSurface)
| کامپوننت | تغییر |
|---|---|
| `AppCard` | بازنویسی روی GlassSurface (امضای فعلی حفظ می‌شود) |
| `AppButton` | Primary: گرادیان برند + هایلایت شیشه‌ای؛ Secondary/Outlined: fill شیشه‌ای |
| `AppTextField` | فیلد شیشه‌ای شفاف با stroke نرم |
| `AppTopBar` | نوار شیشه‌ای شفاف (fill + sheen، بدون بلور چون محتوا زیر آن اسکرول نمی‌شود) |
| `MonetraBalanceCard` | گرادیان غنی‌تر + specular highlights + stroke شیشه‌ای |
| `MonetraTransactionItem`, `SummaryCard`, `MonetraAccountCard` | شیشه‌ای شدن |
| `MonetraChipStrip`, `QuickDescriptionStrip` | چیپ‌های شیشه‌ای |
| `EmptyState`, `ErrorState`, `LoadingIndicator` | دایره آیکون شیشه‌ای |
| `MonetraDatePicker`, `MonetraTimePicker` | کانتینر دیالوگ شیشه‌ای (fill پرتر برای خوانایی روی scrim) |
| `MonetraCategoryIcon`, `MonetraAmountInput` | تنظیم جزئی رنگ |

## ۵. ناوبری — `core/navigation/AppNavigation.kt`
- `LiquidGlassBackdrop` پشت NavHost + `Scaffold` با `containerColor = Transparent`
- `ModernFloatingNavigationBar` → شیشه‌ای با **بلور واقعی Haze**: `hazeSource` روی Box محتوا + `hazeGlass` روی کپسول شناور + FAB شیشه‌ای گرادیانی با glow
- انیمیشن‌های فعلی آیتم‌ها (spring scale، pill، تعویض آیکون) حفظ می‌شوند

## ۶. صفحات (الگوی یکسان: Scaffold شفاف + Surface های محلی → شیشه‌ای)
- **Dashboard** (۶۲۹ خط): `DashboardTopHeader`، `QuickActionsCard`، `FinancialOverviewCard` + نمودار Canvas (گرادیان جدید income/expense)، `RecentTransactionsEmptyCard`
- **Transactions**: `DateGroupHeader`، sheet فیلترها (شفاف + shape XL)
- **TransactionForm**: `TransactionTypeSelector`، دو Selector (فیلد dropdown شیشه‌ای)، `PickerField`، هر ۳ دیالوگ
- **Accounts**: FAB محلی شیشه‌ای + `AddAccountBottomSheet`
- **Analytics**: `MonthlyCanvasChart` + `CategoryProgressRow`
- **Settings** (بزرگ‌ترین صفحه، کاملاً custom): `AppBrandHeaderCard`، `SettingsGroup`، ردیف‌ها، `OptionDialog`، `ThemeOption`
- **Onboarding**: `OptionCard` (انتخاب = glow برند) + `StepIndicator`
- **TransactionDetail**، **SmsImport** (`StatusCard`)، **BankTransactionReview**
- صفحات placeholder (Budgets/Savings/Debts) دست‌نخورده (در ناوبری ثبت نشده‌اند)

## ۷. نکات فنی
- **کارایی:** بلور فقط روی نوار پایین و FAB؛ کارت‌ها شیشه‌ی ساده بدون بلور (مانند خود iOS که blur را فقط برای chrome دارد)
- **RTL/فارسی:** شیشه جهت‌مستقل است؛ فونت، اعداد فارسی و محلی‌سازی دست‌نخورده
- **رشته‌ها:** هیچ رشته جدیدی اضافه نمی‌شود
- **ریسک API Haze:** اگر امضای دقیق Haze 2.x با مستندات فرق داشت، فقط `GlassHaze.kt` اصلاح می‌شود (یا موقتاً Haze 1.7.x با `hazeEffect` + `HazeMaterials`)
